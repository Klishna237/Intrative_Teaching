CSC104

IT Fundamentals & Computer Architecture

Credits: 04 • Theory: 30 Lecture Hours • Practicals: 10 Mandated Labs
CO1 (Remember): Identify PC hardware, motherboard form factors & RAM
CO2 (Apply/Analyze): Troubleshoot hardware, network cabling & OS boot
CO3 (Apply): Configure Windows, Linux & macOS system environments
CO4 (Evaluate): Implement host, endpoint & SOHO wireless security
CO5 (Evaluate): Apply virtualization & cloud infrastructure management

📖 Theory Syllabus (5 Units • 30 Lectures) Launch Portal →

Unit 1: Computer Hardware & Troubleshooting Lectures 1–5

Motherboards, ATX/ITX form factors, LGA/PGA CPU sockets, DDR4/DDR5 RAM latency math, SMPS power rails, NVMe/SATA storage, BIOS/UEFI boot stages, and POST error diagnosis.

Unit 2: Networking Fundamentals & Virtualization Lectures 6–10

Topologies (Star, Mesh, Hybrid), Cat5e-Cat8 cabling, T568A/B crimping, L2 switching vs L3 routing, OSI 7-layer vs TCP/IP encapsulation, IPv4 CIDR subnetting, Type-2 hypervisors.

Unit 3: Mobile Devices & Peripheral Support Lectures 11–15

Smartphone architectures, OLED vs LCD, battery maintenance, USB-C Power Delivery, laser printing 7-stage electrophotographic cycle, print defects analysis, and peripheral interfacing.

Unit 4: Operating Systems & Core Security Lectures 16–20

Windows NT kernel architecture, Executive subsystems, HAL, Registry hives, process management, Windows Defender, NTFS permissions, and system recovery procedures.

Unit 5: SOHO Security & Operational Procedures Lectures 21–30

SOHO router configuration, WPA3 authentication, NAT/port forwarding, malware mitigation, incident reporting, professional ethics, safety, and integrated lab revision.

EXP 01

System Diagnostics & Specifications: Auditing hardware specs using MSINFO32, Device Manager, Task Manager, and CLI.
EXP 03
BIOS/UEFI Firmware Configuration: Modifying boot sequence, enabling Intel VT-x/AMD-V virtualization, and Secure Boot setup.
EXP 04
OS User & NTFS Permission Management: Creating user groups, configuring discretionary access control lists (DACLs) & icacls.
EXP 05
Network TCP/IP Configuration: Static/DHCP IP assignment, DNS resolution, and connectivity testing via ping, tracert & arp.
EXP 06
Wireless SOHO Router Security: Setting up SSID broadcast, WPA2/WPA3 enterprise encryption, DHCP pools, and admin isolation.
EXP 07
Printer Installation & Queue Management: Installing network printers via IPP/LPR, test page rendering, spooler clearing, and print defect triage.
EXP 08
Virtual Machine Provisioning: Hypervisor installation (VirtualBox), guest OS deployment (Ubuntu Linux), and NAT networking.
EXP 09
Windows Security Hardening: Inbound/outbound firewall rules, Windows Defender real-time protection, and Event Viewer security audits.
EXP 10
System Maintenance & Disaster Recovery: Storage optimization, CHKDSK filesystem verification, System Restore points, and recovery images.
CSC205

Cloud Administration & AWS Infrastructure

Credits: 04 • Theory: 45 Lecture Hours • Practicals: 10 Mandated Labs
CO1 (Understand): Explain cloud models (IaaS/PaaS/SaaS) & AWS Global Infra
CO2 (Apply): Deploy EC2 instances, Auto Scaling & Load Balancers
CO3 (Analyze): Configure Amazon S3 lifecycle, EBS volumes & CloudFront
CO4 (Evaluate): Architect Amazon VPC, subnets, NAT & security groups
CO5 (Evaluate): Implement IAM roles, KMS encryption & CloudWatch observability

📖 Theory Syllabus (6 Units • 30 Topics) Launch Portal →

Unit 1: Cloud Concepts & AWS Global Infrastructure Topics 01–05

Delivery models (IaaS/PaaS/SaaS), Type-1/2 hypervisors, AWS Regions, Availability Zones, Edge Locations, AWS Shared Responsibility Model, and Cloud Economics (TCO/Capex vs Opex).

Unit 2: Cloud Compute & Virtualization Topics 06–10

Amazon EC2 instance families, On-Demand vs Spot vs Savings Plans, AWS Nitro offload silicon, Application Load Balancers (ALB), Auto Scaling Groups, and AWS Lambda serverless execution.

Unit 3: Cloud Storage & Content Delivery (CDN) Topics 11–15

Amazon S3 storage tiers, Glacier lifecycle policies, object locking, EBS volume types (gp3, io2), EFS distributed POSIX filesystems, FSx Lustre, and Amazon CloudFront edge caching.

Unit 4: Virtual Private Cloud (VPC) & Networking Topics 16–20

VPC subnet design, public vs private subnets, Internet Gateways (IGW), NAT Gateways, Route Tables, stateful Security Groups vs stateless NACLs, Transit Gateway, and Site-to-Site VPN.

Unit 5: Cloud Databases & Big Data Analytics Topics 21–25

Amazon RDS Multi-AZ synchronous replication, Amazon Aurora storage quorum, DynamoDB key-value partitioning, ElastiCache (Redis/Memcached), and big data pipelines (Redshift, Athena, EMR).

Unit 6: Cloud Security, IAM & Cost Governance Topics 26–30

IAM least-privilege policies, STS assume-role tokens, KMS envelope encryption, CloudWatch monitoring & alarms, CloudTrail audit trails, AWS WAF, and AWS Well-Architected Framework.

CSC204

Server Administration & Enterprise Infrastructure

Credits: 04 • Theory: 45 Lecture Hours • Practicals: 10 Mandated Labs
CO1 (Remember): Identify server chassis, NUMA multi-socket & ECC architectures
CO2 (Apply): Deploy Windows Server/RHEL & Type-1 bare-metal hypervisors
CO3 (Analyze): Configure Active Directory DS, DNS, DHCP & Failover Clusters
CO4 (Evaluate): Sizing DAS/NAS/SAN storage, hardware RAID & write penalty
CO5 (Evaluate): Implement PKI, CIS server hardening & bare-metal disaster recovery

📖 Theory Syllabus (6 Units • 30 Topics) Launch Portal →

Unit 1: Server Hardware & Subsystems Topics 01–05

Rack, blade & tower chassis, Out-of-Band BMC (iDRAC/iLO), multi-socket NUMA bus topology, multi-channel ECC registered RAM, PCIe 5.0 risers, OCP 3.0 mezzanine, and 2N redundant power.

Unit 2: Server Installation & Virtualization Topics 06–10

Automated unattended installations (WDS, Kickstart), GPT vs MBR, ReFS vs XFS filesystems, Type-1 bare-metal hypervisors (ESXi, KVM), hypervisor memory ballooning, and vSwitch VLAN trunking.

Unit 3: Server Roles & High Availability Topics 11–15

Active Directory DS & 5 FSMO roles, DNS zones & records, DHCP failover clustering, IIS worker processes vs NGINX, WSUS patching pipelines, and Windows Server Failover Clustering (WSFC).

Unit 4: Storage Technologies & RAID Architecture Topics 16–20

DAS vs NAS vs SAN topologies, iSCSI initiator/target, Fibre Channel (FC), Hardware RAID 0/1/5/6/10 with XOR math, RAID write penalty formula, IOPS sizing, and Storage Spaces Direct (S2D).

Unit 5: Server Hardening, PKI & Security Topics 21–25

CIS security benchmarks, Group Policy Objects (GPO), Active Directory Certificate Services (AD CS) PKI, Kerberos ticket exchange, host firewalls, BitLocker/LUKS2 encryption, and SIEM forwarding.

Unit 6: Networking, Disaster Recovery & Triage Topics 26–30

NIC Teaming & LACP link aggregation, enterprise port matrix, Disaster Recovery RTO/RPO models, 3-2-1 backup topology, VSS shadow copies, and kernel panic/BSOD memory dump analysis.

🎯 Curriculum Accreditation & Bloom's Taxonomy Alignment

NBA / NAAC Compliance

All 3 curricula are designed according to Bloom's Revised Taxonomy levels: Remember (Level 1), Understand (Level 2), Apply (Level 3), Analyze (Level 4), and Evaluate (Level 5). Students progress from foundational hardware/network identification into deploying enterprise cloud architectures, implementing RAID fault tolerance, hardening zero-trust security postures, and resolving system crash dump forensics.
