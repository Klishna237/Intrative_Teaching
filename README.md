## 🎯 Architectural Highlights & Design System (Master Gold Standard)

Every subject portal adheres to the external gold-standard visual and technical blueprint (`CSC104: IT Fundamentals`):
1. **Collapsible ToC Drawer Navigation (`#tocDrawer`)**: Single-accordion unit headers (`.toc-unit-header`), section badges, topic counts, smooth scrolling, and sister portal jump pills.
2. **Typography & Styling**: Embedded Inter & JetBrains Mono fonts, high-contrast dark palette (`#0c1017` / `#161b22`), custom color-coded callouts (`.callout-deep`, `.callout-mnemonic`, `.callout-alert`, `.callout-tip`, `.callout-key`), and custom-styled comparison tables.
3. **Interactive Scoring Engine (`.mcq-card`)**: Dynamic evaluation with instant green/red option feedback, score trackers, and master answer verification keys.
4. **Subjective Accordions (`.subj-card`)**: Collapsible 5-mark and 10-mark examination problems with hidden answers revealed on click.
5. **Interactive Sandboxes & Calculators**: Dual Windows CMD / Linux Bash sandbox for IT Fundamentals, live AWS CLI sandbox for Cloud Administration, and dual PowerShell 7 / RHEL 9 Bash sandbox for Server Administration.
6. **100% Offline Single-Page Architecture**: Zero external npm, Node.js, database, or web server dependencies; opens instantly in any browser.
